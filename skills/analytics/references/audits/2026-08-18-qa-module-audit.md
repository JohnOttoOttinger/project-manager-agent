# Q&A module audit — Oddtoe — 18 Aug 2026

Which pages would gain most from adding or rewriting an FAQ module, judged on
Search Console position data rather than opinion.

**Source:** GSC, 180 days to 17 Aug 2026, page and page+query dimensions (1,180
query rows across 34 pages). Page HTML fetched the same day and parsed for
question-shaped headings and `FAQPage` schema. Ahrefs contributed nothing — its
free tier estimates what GSC measures exactly, and competitor data is locked.

## The prioritised list

Ranked on: impressions already earned × how movable the position is × how thin
the current Q&A is. "Strike" is impressions on queries sitting at positions
4–20, where an FAQ module can realistically move something.

### Leave alone

- `/artist-designer/kinetic-sculptor/` (17 Qs + schema) and
  `/artist-designer/installation-artist/` (15 Qs + schema) are already the
  best-built pages on the site.
- `/animation-agents/` earns the most clicks on the site (599) but at position
  18.3, and its audience is animators seeking representation rather than people
  who commission work. Growing it grows the wrong traffic.

## Three findings worth acting on separately

**1. AI assistants are already reading the new money pages.** Two queries in the
data carry the `-site:reddit.com -site:twitter.com` filter signature that LLM web
search uses:

| Query | Page | Position |
|---|---|---|
| `"brand activation" -site:reddit.com -site:twitter.com…` | /brand-activation-ideas/ | **1** |
| `"ai artist" -site:reddit.com -site:twitter.com…` | /what-is-generative-ai-animation/ | **4** |

Both are pages built with the money-page kit, and both carry FAQPage schema. It
is a small sample, and it is the only direct evidence so far that the GEO work is
landing.

**2. Five pages are competing with each other on the same brand query.**
`oddtoe prop maker melbourne` and its variants surface `/about-oddtoe/`,
`/portfolio-aggregate/`, `/about-oddtoe/investment/`, `/studio/documentary-animator/`
and `/articles-ideas/`, all at positions 4–9, with zero clicks between them. No
single page owns the term. An FAQ module will not fix this; it needs one page
designated as the answer and the others pointed at it.

**3. Question-shaped queries are only 516 impressions over 180 days.** Chasing
question traffic directly will not move much. The case for FAQ modules here rests
on machine extraction — schema, and answers phrased as answers — which Search
Console does not measure at all. Judge this work on whether Oddtoe starts
appearing in AI answers, not on a click increase.

## Method note

Question headings were detected as any `h1`–`h6` whose text ends in a question
mark, and schema as the presence of `FAQPage` in the page source. A page could
carry questions in body copy that this misses. Counts here are the machine-visible
ones, which is the point.

## Decisions taken during the rollout

**Existing questions were all kept.** Otto's instruction was add-below, never
replace — so the Edward Scissorhands and Michael Jordan questions on the topiarist
page stayed, and the schema now covers old and new together.

**The blog post got HTML, not an accordion.** `experiential-design-techniques-examples`
is a post with no shortcodes and a light background; a dark accordion would have
looked imported. It uses the post's own `<h2><strong>` Bebas pattern plus the same
JSON-LD. Flagged to Otto — easy to switch to an accordion if he prefers.

**No new internal links.** The link question was raised and never signed off, so
answers are plain text apart from the one link on 12203 that Otto saw in the preview.

**Row backgrounds are taken from each page, not the kit.** The kit's FAQ row
inherits the page background, which renders white-on-white on pages that set their
colour per row. The script now reads the nearest preceding row's colour.

## Two bugs caught before they shipped

**CRLF destruction.** Reading page content through Python in text mode silently
converts `\r\n` to `\n`. On page 12203 that was 38 line endings — the content would
have looked identical and rewritten every one. All reads and writes now use
`newline=''`, and the script asserts the CR count is unchanged.

**Copy drift.** Every page asserts that content outside the inserted or extended
block is byte-identical to what was fetched. On 12203, where two approved copy
edits were also applied, the diff was checked by hand: exactly five changed
regions, all inside the two approved spots.

## Copy changed outside the FAQ modules

Only on `/studio/generative-ai-animator/`, both approved by Otto:

- H3: `One animator. The full pipeline.` → `The full animation pipeline, but art
  directed by a human.`
- Body: `A single animator … a studio of fifty` → `A small studio … fifty people`

Reason: on the commissioning pages a solo framing reads as delivery risk. A scan
of all 34 pages found this language **only** on this one page, so the exposure was
contained. See the competitor register — every rival shows a team, and none states
a headcount.

## Post-rollout fixes — 18 Aug 2026

Otto reviewed the live pages and flagged four things.

| Page | Problem | Fix |
|---|---|---|
| roboticist | 206px of dead space above the Q&A — the row above ends with its own 120px spacer, and the FAQ row added 80 more | FAQ row's top spacer 80 → 20 |
| generative-ai-artist | same, 190px (preceding spacer 110) | 80 → 20 |
| topiarist | Q&A row was `rgba(31,61,12,0.13)`, a translucent olive between two dark rows | → `#252525`, matching the two rows above |
| character-designer | tan `#c39f76` links on the `#c6acb6` pink rows measured **1.17** contrast — effectively invisible | scoped CSS, plum `#26161f` at **8.20**, wine `#5c2b3f` hover at **5.33** |

### The link CSS

Scoped by `.page-id-13701 .vc_row:not(.dfd-background-dark)`, so it only touches
the pink rows and leaves the dark rows on their existing tan. Injected as a
`vc_raw_html` style block at the top of the page content.

Measured against `#c6acb6`:

| Colour | Ratio | WCAG AA body |
|---|---|---|
| tan `#c39f76` (was) | 1.17 | fail |
| **plum `#26161f`** | **8.20** | pass |
| **wine `#5c2b3f`** (hover) | **5.33** | pass |
| olive `#8a8f6a` | 1.60 | fail |
| sand `#ddccb1` | 1.34 | fail |

Only plum and near-black clear AA on that pink. Sand and olive are both too
light — worth knowing before any other light-background row gets links.

### Spacer lesson for the next rollout

The FAQ row's own top spacer is not the whole gap. Preceding rows carry their
own trailing spacers, and they vary from 30px to 350px across these pages. Read
the preceding spacer before choosing, or the total lands anywhere between 110px
and 430px.
